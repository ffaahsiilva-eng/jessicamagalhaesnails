# Agendei Manicure

Crie um app para dispositivo celular para manicure, com tabela de preços, sistema de agendamento com data e hora clicavel para todos os clientes verem  e enviar por whatsapp, fotos, redes sociais, sistema de login de clientes,numero whatsapp, lembrete para clientes.
